  • 1The library chips cover the whole page; Live means it updates by itself.
  • 2One progress card for everything Library is doing: percent, what has been found by kind, and the counts. The same wording appears on the batch line when it finishes.
  • 3Working now: standard tiles with the flush status label for what Library is doing to that title. Clicking a tile opens that item.
  • 4Background work (AI, maintenance) is a plain line with no bar; it is counted in the card's total. The line only appears while there is some.
  • 5History controls: search, type, date range and sort by time. Search filters instantly.
  • 6History is a vertical timeline: a round date bubble for each batch on a line, headed by month and year; each heading collapses (the current month is open, older months and years start collapsed with their batch count), so a day is a click or two away. The newest line says Active while it runs. Clicking a line opens it in place into two rows of standard tiles that load as you scroll, with a filter by kind; episodes stack into a show, tracks into an album, other videos into a root folder.

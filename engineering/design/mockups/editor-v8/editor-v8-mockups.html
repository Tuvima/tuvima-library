  1. 1Search filters the list as you type (titles, numbers, file names), useful on a show with many episodes.
  2. 2Episodes: number, still, title and a mark. The one being edited is highlighted. Choosing one switches the editor to it in the same window; changes already typed in other episodes are kept and shown in Review changes.
  3. 3An amber dot means that episode has unsaved changes.
  4. 4Supporting files of this level (PDFs, trailers, Extras) are listed under the episodes; choosing one opens it. No Reorder button, no "All supporting files" or "Browse files and folders" rows: matched episodes take their order from the match, and the folder button beside the dropdown opens the browser.
  5. 5Reorder videos is offered only on a video collection where Library is still guessing the order, never on matched episodes. Pressing it puts the list in Reorder mode.
  6. 6Each row gets a handle: drag, or Move up / Move down from the keyboard. The new order is held in the list only.
  7. 7Save order stages one change (shown once in Review changes); Cancel, Escape or closing the list throws it away. On Save changes, with file write-back on, files in Managed folders are renamed to the new order; Read-only folders are never touched. If a later match fixes the order, the files are renamed again.

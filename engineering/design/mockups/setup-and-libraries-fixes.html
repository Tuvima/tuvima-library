  • 1The card is a row of equal cells: icon above, then the count, then the kind's name. It wraps to a second row when there are more kinds than fit, and shows two per row on a phone.
  • 2Each kind has its own color from the design system: movies, TV, music, audiobooks, books, comics and documents. A kind without one (such as Photos and videos) uses its area's color.   • 3Photos and Personal videos are one row, "Photos and videos", with one Edit window listing all of its folders. Documents stays its own row once it has a folder.
  • 4A library with no folders is not listed, here or in setup. The struck-through line is only to show what disappears; it is not part of the screen. Add library is how a library appears. The chip counts and the card count only what is listed.
  • 5The Import folder row is the one exception today: it is always listed, even before a folder is chosen, because this row is where you choose it (question 3).

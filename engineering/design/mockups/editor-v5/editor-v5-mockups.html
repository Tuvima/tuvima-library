Editor v5: header navigation and supporting files

A revision of the Locked v4 and v4.1 editor. The Contents and Files tabs are gone: you move around a show, a course or an album from the header (home button, Season or folder dropdown, item dropdown), and a folder button at the end of the item list opens the file browser. Supporting files (guides, worksheets, clips, pictures) are items you can edit. Fields are locked until you unlock them. The header background is a gradient made from the cover's own two main colours; there is no banner picture. The footer says where edits go.

Every screen is the app's own look (Look pass v2 colours, 44 px controls). Pictures are stand-in colour blocks. Screens are 1440 px wide unless they say otherwise. Numbered markers match the notes under each screen.

  1. 1The same shell for a file. Cover and gradient come from the show. The facts line gives the type, pages and size, and a "Supporting file" chip says what this is.
  2. 2The item dropdown shows the file's group above its title, with a type badge instead of a still. The home button and Season dropdown work as on an episode.

  4. 4Suggest details from the document fills Title and Description from the file's own metadata and first page (local only; no provider). Nothing is kept until you save.
  5. 5Group and Role. Group is a dropdown you can type into: this show's groups, or any new name. The Engine also reads a group from a named subfolder (Extras/Character guides). Role is a fixed list that depends on the type: Guide, Worksheet, Transcript, Notes, Booklet for documents; Trailer, Featurette, Behind the scenes, Deleted scene, Interview, Clip for videos; Pictures; Other. The folder and file-name words that set a role are a documented naming scheme (public docs page "Naming supporting files"), so a tidy library needs no editing. Archives, .nfo files, subtitles and other sidecars are never supporting files: they stay hidden, and the Folders and files view lists them greyed as "Not shown in the library".
  6. 6Belongs to is the file's scope: the show, a season or one episode. It was read from the folder (the hint says so); picking another value in the dropdown is the override, and "Use folder location" appears to go back. In a Managed folder a changed Belongs to moves the file into that folder on Save, with the amber footer warning first; in a Read-only folder nothing moves. The scope decides where the file is listed and whose visibility and delete rules it follows.
  7. 7Shown alongside (optional) adds the file to one episode's own Extras without changing where it belongs. Hidden when the scope is already an episode.
  8. 8Quick facts carry the file facts (original file name, folder, read-only) and a Preview button, which opens the Preview tab.

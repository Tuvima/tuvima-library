5 · Add library, step 1: What is it?

Add library asks one question per screen. Step 1 is the content type. A row of area tabs at the top is pre-selected to the area you clicked Add from, so only that area's three or four types show and nothing scrolls. A type that already has a library is shown with a reason instead of being hidden.

Step 2 is the folder browser itself, not a form with a Browse button that opens a third window. Folder names appear at once; the check of the selected folder runs underneath and never blocks browsing. The name is a quiet line in the footer, already filled in.

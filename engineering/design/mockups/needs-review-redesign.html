  1. One number. The tab shows the same number as the Activity pill, the account menu and (later) the Settings menu. It counts items, so two episodes in one row still count as two.
  2. One plain sentence says how much is waiting. No "Not matched" or "Not sure" labels anywhere; the only name is Needs Review.
  3. Two controls only: a library filter (shown when there is more than one library) and search. The three-way All / Not matched / Not sure switch and the "Try again for all · Keep all" text links are gone.
  4. Ready to confirm comes first because it is the quickest: Library has one likely answer and only wants a yes. Ticking the box beside a heading ticks every row under it.
  5. Use this accepts the suggestion in one click. The row then shows "Matched to …" (screen 2) and the number drops. The second line under the suggestion says why Library thinks so, or how sure it is.
  6. Fix opens the editor window over this page on Match, as it does today. The "..." menu holds the rarer actions (screen 2).
  7. Choose a match: Library found more than one answer and will not guess.
  8. The choices sit in the row with their covers, so most decisions need no extra window. If none is right, Fix opens the full search. (This is new; today the row shows a percent and you must open the editor. See question 3.)
  9. Film or TV show? The existing "this may be a TV show" decision uses the same choice layout instead of its own card.
  10. No match found: Library searched and found nothing close enough. The grey text on the right says whether it will try again by itself, so you know if you can simply leave it.
  11. Files from one show, album or book series share one row ("2 episodes"). The arrow opens the list of files; Fix on the top row opens the show so one correction can fix them all.
  12. File problems are not about matching: a file that cannot be read, cannot be saved to, or clashes with another file's name. The button offered is the one that helps (Try again), not Fix.
  13. Kept items can come back. "Keep as it is" hides an item from this list. This line appears only when something is hidden, and brings those items back into view.

  1. A finished row stays as one quiet line until you leave the page, so you can see what just happened without a pop-up message. If the action fails, the row stays as it was with the reason in red under it.
  2. The "..." menu: Try again (search once more now), Keep as it is (stop asking about this item), Show in Activity (what Library did with this file), and Delete (asks once, as everywhere else). Menu rows that cannot apply are left out, never greyed.
  3. The bar appears only when something is ticked. Use suggestions accepts every ticked row that has one suggestion; Edit opens the same editor window for several items, as in other lists. It replaces the old "for all" links, which acted on everything the filters showed.

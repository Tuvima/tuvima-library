  1. Sticky bar as in the item editor. Save changes stays off until the file has no problems. Reset to Tuvima's version copies back the pristine file that ships with Library; keys and settings are kept.
  2. Coloured text with line numbers; the line with a problem is tinted red.
  3. Problems (stop saving) and things to know (do not) in plain words with the line. Fields that widen what a plugin may reach (id, kind, network hosts, permissions) are locked in this editor.
  4. Review changes appears after pressing Save changes and shows exactly what differs. Saving reloads the plugin and runs its check. Editing is desktop only.

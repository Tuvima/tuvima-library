## 3. Rules for every packet
- **One feature per branch, one git worktree per packet**, outside `Repos`, max two worktrees/builds at a time. Remove the worktree and its bin/obj after merge. Branch names `claude/<topic>` are what `auto-merge.yml` merges; branches auto-delete on merge plus a nightly sweep; end state is only `main`.
- **Merge = add the `ready-to-merge` label** (`gh api -X POST repos/Tuvima/tuvima-library/issues/N/labels -f "labels[]=ready-to-merge"`). `gh pr merge` is blocked. Standing OK from Shy: label once CI is green and an independent review passes, **except security or privacy changes (including access/visibility), which need Shy's own yes typed by Shy**.
- **Independent review** (fresh context, not the author) before label for multi-component, data-model or security packets. Every feature ends with a full-feature review plus a full restore/build/test run: `dotnet restore MediaEngine.slnx`, `dotnet build MediaEngine.slnx --no-restore`, `dotnet test MediaEngine.slnx --no-build`; aim 0 errors, 0 warnings. Also `dotnet format whitespace --verify-no-changes`.
- **Known reds on main (ignore, do not fix in unrelated PRs):** Windows-path Dashboard tests, "Audit external links", "Smoke linux/amd64" and "Smoke linux/arm64" container smoke.
- **Flaky (pass on rerun, say so in the PR):** SQLite ObjectDisposed, ApplicationEventDispatcherTests, bUnit WaitFor / UiShellRenderTests, HistoricalIngestion_DeepPage, ViewSharedSourceServiceTests, ViewSourceIndexingHostedServiceTests, EnrichmentPipelineExecutionGateTests, ManagedAccessUsersTests, ManagedAccessHouseholdTests, Secure_RefusesAnAccountThatIsAlreadySecured, FolderJobServiceTests, Ingestion FolderMergeTests, one Performance timing test under full parallel run, CinematicHeroCarouselRenderTests.ExplicitPausePersistsAfterFocusAndHoverLeave, PluginLoreRepositoryTests.UpsertExtractionResultAsync_PreservesObjectSubtype.
- **Pitfalls that fail guardrails:** `::deep`, inline styles and raw `<input>` in Razor; touch targets need min-height 48px; new tables need an entry in `DatabaseStartupSafetyTests`; analyzer IDE0011 (braces); wire DTOs belong in `Contracts` and the wire-type-inventory fixture must be regenerated; run `dotnet format whitespace`; bUnit clicks must run on the renderer thread. Some config tests fail locally in a worktree with "Could not find repository root" but pass in CI.
- **Running the app:** set `ASPNETCORE_ENVIRONMENT=Development` (or use `tools/Start-TuvimaApp.ps1`) or Blazor scripts 404 and the page is blank. Use `dotnet run --no-launch-profile`. Engine http://localhost:61495 then Dashboard http://localhost:5016 (phone: http://192.168.0.177:5016). Binding to the LAN needs Shy's OK (given for the test app). Shy's test data store on the desktop test app: never delete it. Real test media `Z:\Development\testing\media\real_media` is read-only input. Use a second port for live checks. Never `taskkill` all dotnet.exe; stop only your own processes.
- **Disk/cleanup:** work runs on Shy's machine/server where space is precious. Delete test databases, temp folders, generated media, test results/coverage, published outputs and any app instances you started. Do not write large files outside the worktree. Do not leave background processes. Desktop has no ffmpeg and no Android toolchain.
- **Product guardrails (CLAUDE.md):** no all-in-one management workspace (corrections happen in the shared editor over the item page; Needs Review is the exception workflow); no "Registry" naming; SQLite + hand-written SQL (Dapper), `IDatabaseConnection.CreateConnection()` in request paths; first-party `App*` components (no MudBlazor); `Contracts` solely owns wire types; no silent `catch {}`; security: no guest keys, no localhost admin, no seed-owner fallback.
- **Product decisions to respect:** Documents-off profiles must never learn a document exists (same answer for "no card" and "unknown id"). Profiles: content limits Everything/G/PG/PG-13/R, Kids default PG. Native phone apps portrait-only except video. Offline downloads native apps only. Phone nav: 3-tab dock (Home, Search, My Library), hamburger mirrors desktop nav, icon-only logo on phones. "My Library" name on all form factors. Native photo access is a separate opt-in at pairing; documents stay 404 to apps. UI standard: clean, fast, phone/desktop/TV; benchmark Plex/Jellyfin/Plezy. Dashboard is dark-only; brand purple #8852FC.
- **Talking to Shy:** plain English, say why in product terms (Maintenance, Extensibility, Privacy, Reliability, Performance), end plans and completed tasks with a "Plain English summary". No PR reviewers, no @mentions, no PR comments unless required. PR bodies start with the attribution block given by the harness. Commits: never `git add -A`; never commit `*.db`, `bin/`, `obj/`, screenshots (use ignored `.tmp/`).
- **Docs in the same change** when behaviour, config, endpoints, schema or navigation change (table in CLAUDE.md section 6).

# Engineering records

This directory holds maintainer plans, design working files, reports, and review evidence that are visible in the repository but are not part of the published documentation site.

Put new dated engineering plans, reports, and notes under this directory. Keep product guidance intended for the documentation site under docs/.

QA screenshots belong in the ignored .tmp/ workspace when local review needs them. Existing screenshots removed during cleanup were not copied into .tmp/.

The docs-overhaul folder contains the preserved inventory and its separate cleanup execution record.

# License

Tuvima Library is free and open-source software under the GNU Affero General Public License, version 3. Read the [project license](../../LICENSE) for the complete terms.

## Run your own library

You can run Tuvima Library on your own machine. There is no Tuvima subscription or paid feature tier. Metadata providers and optional services may have their own terms or charges.

## Modify or share the software

The AGPL protects access to the covered source code when the software is distributed. It also addresses users interacting over a network with a modified version. Consult the license before distributing changes or providing a modified service.

## Build a plugin

Plugins load into the Engine process. The way a plugin combines with the application can matter to its licensing. Consult the license; this page is not legal advice. Check dependency and provider terms as well.

## Contribute

Contributions are made under the project's license. Preserve copyright notices and check that new tools and assets have compatible terms. Fonts and media assets have their own notices.

Read the documentation site's [complete third-party license notices](/licenses/THIRD-PARTY.txt), including the bundled fonts and local search tools.

Tuvima Library uses the AGPL because a library built around ownership should remain inspectable, modifiable and available to its users. The project welcomes improvements that can be shared back with the community.

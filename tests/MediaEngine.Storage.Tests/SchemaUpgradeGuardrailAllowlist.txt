src/MediaEngine.Api/DevSupport/DevHarnessResetService.cs | Development harness reset: drops tables to clear a disposable dev data store. It does not define or change the production structure.
src/MediaEngine.Storage/Backup/PersonalStateBackupRepository.cs | Backup export: reads the live table and column structure (names, NOT NULL, defaults) with a read-only pragma_table_info query, so it never selects a column that does not exist. It changes no structure.
